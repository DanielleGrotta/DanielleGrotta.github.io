# Danielle Grotta · Portfolio

Product Designer & UX Engineer portfolio, built with React, TypeScript and Vite. Bilingual (EN/PT), light and dark themes.

Each case includes a working demo built in code:

- **One survey, 40+ brands**: the same survey component re-skinned by brand tokens.
- **From one key visual to every screen**: a campaign system adapting to flyer, email, TV and kiosk formats.
- **NPS, CSAT and CES at a glance**: a CX dashboard with filters, sparklines and NPS breakdown.

Client work is under NDA. All brands and data in the demos are fictional.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds and publishes to GitHub Pages via `.github/workflows/deploy.yml`.
In the repository settings, set **Pages > Source** to **GitHub Actions**.

## Edit content

All text lives in `src/content.ts` (English and Portuguese side by side).
